## Minimum viable setup

Start with **just #1–#4**. That's ~20 emails/week → plenty of raw material.
Add others only if content feels thin.

## After subscribing

1. Check each lands in Gmail (look in Promotions tab, drag to Primary)
2. Note exact **sender addresses** — we need them for the script's Gmail filter:
   - TAAFT: `hi@mail.theresanaiforthat.com`
   - TLDR AI: check the From field after first issue arrives
   - Ben's Bites: check From field
   - The Rundown: check From field
3. Paste the sender addresses into `02-PRODUCT.md` § Sources config
